# 📊 Análisis de Logs en Linux  

## 📌 Descripción del proyecto  

En este proyecto analicé archivos de logs utilizando comandos de Linux para identificar errores y actividad relevante dentro del sistema.  

Este proyecto lo realicé como parte de mi aprendizaje en ciberseguridad, enfocándome en el análisis de información a partir de logs.  

---

## 🛠️ Herramientas utilizadas  

- Linux
   
- Bash
   
- grep
  
- head  

---

## 🔍 Búsqueda de errores  

bash
grep error server_logs.txt

Este comando permite filtrar y mostrar únicamente las líneas que contienen la palabra "error".

📄 Visualización rápida

head server_logs.txt

Permite ver las primeras líneas del archivo, útil para analizar logs grandes.

🔎 Búsqueda de información específica

grep jhill Q2_deleted_users.txt

Permite encontrar datos concretos dentro de un archivo.

🔗 Uso de pipes
ls | grep Q1

Permite filtrar archivos por nombre.
